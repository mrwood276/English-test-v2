# Instructions for AI coding agents

Before doing anything in this repository, read `.ai/00_AI_RULES.md`, then the other files in `.ai/` in the order it lists, then inspect the actual source code.
`.ai/` is shared project memory between AI agents (Claude, Codex/GPT). It is **not** the source of truth: source code, the live database, tests, and git history outrank it. Update `.ai/` after every meaningful change and never rebuild features that `.ai/03_FEATURES.md` marks as complete.
